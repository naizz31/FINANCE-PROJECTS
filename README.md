# Finance Projects

Personal projects in markets and quantitative finance, built to test the theory on real numbers.

| Project | What it covers |
|---|---|
| [derivatives-pricing](derivatives-pricing%20%281%29/derivatives-pricing) | Black-Scholes and Greeks, binomial tree (European/American), bond duration and convexity, forwards and futures hedging, Hull-White short-rate model |
| [structured-products](structured-products/structured-products) | Monte Carlo pricer for capital-protected notes, reverse convertibles and Athena/Phoenix autocalls: fair coupon, Greeks, call probabilities, capital-loss risk |

Each folder has its own README with the method, results, charts and limitations. Both projects are in Python (NumPy, SciPy, Matplotlib) and come with unit tests (`pytest`).
